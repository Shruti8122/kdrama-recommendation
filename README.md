# 🎬 K-Drama Recommendation System (Frontend)

This is the React frontend for the K-Drama Recommendation System.  
It connects to a custom-built FastAPI backend to fetch and display similar drama recommendations based on user input.

## 🌐 Live Demo
https://kdrama-recommendation-8s2s.onrender.com

## 🔗 Backend API
https://github.com/Shruti8122/kdrama-api.git

## ⚙️ Tech Stack
- React
- Bootstrap
- FastAPI (Backend)
- Render (Deployment)

## ✨ Features
- Search for a K-Drama
- Get similar recommendations
- Dark mode toggle
- Responsive card layout
- Integrated REST API

## 📚 Project Purpose
This project was built as a learning and portfolio project to practice:
- API development
- React integration
- Full-stack deployment
- Clean UI design
